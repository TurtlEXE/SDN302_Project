# Kiểm thử xuyên hệ thống

Vị trí dành cho kiểm thử luồng React → API → MongoDB và tích hợp liên quan. Chưa có bộ test hoặc kết quả chạy.

Các phase frontend bổ sung kiểm thử phù hợp; P20 chạy bộ nghiệm thu toàn hệ thống. Kiểm thử backend unit/integration nằm trong `server/tests/`. Xem [kế hoạch phát triển](../../docs/planning/development-plan.md).
