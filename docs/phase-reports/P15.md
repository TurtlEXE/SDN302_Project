- **Mục tiêu và phase trong kế hoạch:** Phase P15 — Nền React, layouts và xác thực.
  1. Khởi tạo hoàn chỉnh ứng dụng client React trên nền Vite tại thư mục `client/` với router, styling Tailwind CSS, thư viện biểu tượng Lucide React và cấu hình dev server proxy chuyển tiếp `/api` và `/uploads` về backend cổng 5000.
  2. Xây dựng HTTP API Client (`api-client.js`) và cơ chế quản lý token bảo mật trong bộ nhớ RAM (`token-memory.js`):
     - Tuyệt đối không lưu Access Token trong `localStorage` hay `sessionStorage`.
     - Tự động đính kèm `Authorization: Bearer <token>`, `X-CSRF-Guard: 1` cho các mutation requests và cấu hình `credentials: 'include'`.
     - Cơ chế Mutex Single-flight Refresh: khi nhận mã 401 `TOKEN_EXPIRED`, xếp hàng các request đồng thời, chỉ gọi duy nhất 1 request `/api/v1/auth/refresh`, sau đó phát lại các request bị hoãn; không kích hoạt refresh khi gặp 403 hoặc lỗi khác.
     - Điều phối đa tab qua `BroadcastChannel` để đồng bộ tức thì trạng thái đăng xuất hoặc thu hồi phiên giữa các tab mà không cần lưu token vào storage.
  3. Xây dựng `AuthContext` và `AuthProvider`:
     - Tự động bootstrap phiên đăng nhập qua silent refresh khi tải lại trang web (dựa trên cookie `refresh_token`).
     - Cung cấp các hành động: `login`, `register`, `logout`, `logoutAll`, `refreshProfile`.
     - Cung cấp trạng thái: `user`, `role`, `isAuthenticated`, `isLoading`, `authError`.
  4. Xây dựng hệ thống Layouts chuẩn mực, responsive:
     - `PublicLayout`: Dành cho khách vãng lai, gồm Header công khai với logo và menu điều hướng, nút Đăng nhập / Đăng ký, Footer thông tin liên hệ và bản quyền.
     - `CustomerLayout`: Dành cho Khách hàng đã đăng nhập, thanh điều hướng, menu người dùng, liên kết đơn đặt và hồ sơ cá nhân.
     - `DashboardLayout`: Dành cho Quản trị viên (Admin) và Chủ sân (Owner) với thanh bên (Sidebar) điều hướng phân quyền, breadcrumbs và drawer hỗ trợ thiết bị di động.
  5. Xây dựng Bộ bảo vệ tuyến đường (`RouteGuard`):
     - `ProtectedRoute`: Kiểm tra trạng thái đăng nhập, lưu URL trước đó để chuyển hướng sau khi đăng nhập (`redirect=...`).
     - `RoleRoute`: Kiểm tra vai trò của người dùng (ADMIN, OWNER, CUSTOMER); nếu không có quyền điều hướng sang trang 403 `Forbidden`.
     - `PublicOnlyRoute`: Ngăn người dùng đã đăng nhập truy cập lại trang Login/Register, tự động điều hướng về dashboard tương ứng.
  6. Xây dựng các trang giao diện xác thực và hồ sơ:
     - `LoginPage`: Đăng nhập với email và mật khẩu, kiểm tra validation, hiển thị lỗi rõ ràng.
     - `RegisterPage`: Đăng ký tài khoản Khách hàng, kiểm tra độ mạnh mật khẩu, hướng dẫn xác thực email sau đăng ký.
     - `VerifyEmailPage`: Nhận token từ query URL, có nút bấm "Xác nhận kích hoạt" (POST, không tự tiêu thụ token trên GET).
     - `ActivateOwnerPage`: Nhận token từ URL lời mời của Admin, biểu mẫu thiết lập mật khẩu lần đầu (POST).
     - `ForgotPasswordPage`: Biểu mẫu yêu cầu gửi liên kết đặt lại mật khẩu.
     - `ResetPasswordPage`: Nhận token đặt lại mật khẩu từ URL, biểu mẫu nhập mật khẩu mới (POST).
     - `ProfilePage`: Xem và cập nhật thông tin cá nhân (họ tên, số điện thoại), đổi mật khẩu, xem trạng thái tài khoản và nút đăng xuất khỏi tất cả thiết bị (`logoutAll`).
     - `ForbiddenPage` (403) và `NotFoundPage` (404).
  7. Viết bộ kiểm thử tự động cho Client (AuthContext, API client, Token Memory, RouteGuard) và kiểm tra quá trình build sản xuất.
  8. Lập báo cáo bàn giao chi tiết, bảng SHA-256 manifest và cập nhật `phase-status.json`.

## 2. Đầu việc và kết quả

  - Cấu hình dự án React 18 trên nền Vite v5.4.
  - Tích hợp Tailwind CSS v3.4 với bảng màu thể thao hiện đại (`brand-500: #10b981`), font chữ Inter sắc nét, tuân thủ hướng dẫn art direction không slop.
  - Cấu hình máy chủ phát triển Vite tại cổng 3000 (khớp với `CLIENT_ORIGIN=http://localhost:3000`) cùng bộ chuyển tiếp proxy `/api` và `/uploads` về backend cổng 5000.
- [x] **Đầu việc 2 — Xây dựng `token-memory.js`, `api-client.js` với single-flight refresh mutex và multi-tab broadcast sync:**
  - `token-memory.js`: Lưu trữ Access Token duy nhất trong biến bộ nhớ RAM, tuyệt đối không chạm vào `localStorage` hay `sessionStorage`.
  - `api-client.js`: Tự động cấu hình `credentials: 'include'`, đính kèm `Authorization: Bearer <token>`, thêm `X-CSRF-Guard: 1` cho mọi mutation requests (`POST`, `PUT`, `PATCH`, `DELETE`).
  - Single-flight Refresh Mutex: Khi gặp mã 401 `TOKEN_EXPIRED`, chỉ gửi đúng 1 request `/api/v1/auth/refresh`, đưa các request đồng thời khác vào hàng đợi và phát lại tự động sau khi có token mới. Không refresh khi gặp 403 hoặc lỗi nghiệp vụ khác.
  - Điều phối đa tab qua `BroadcastChannel('sport_booking_auth')`: Đồng bộ tức thì sự kiện đăng xuất và thu hồi phiên giữa các tab trình duyệt.
- [x] **Đầu việc 3 — Xây dựng `AuthContext.jsx` và `useAuth` hook với bootstrap refresh khi khởi chạy:**
  - Quản lý trạng thái xác thực tập trung: `user`, `role`, `isAuthenticated`, `isLoading`, `authError`.
  - Bootstrap im lặng (`POST /api/v1/auth/refresh`) khi tải lại trang web; nếu có cookie refresh hợp lệ sẽ phục hồi phiên tự động mà không cần lưu token vào đĩa.
  - Cung cấp các hàm tiện ích: `login`, `register`, `logout`, `logoutAll`, `refreshProfile`, `updateProfile`.
- [x] **Đầu việc 4 — Xây dựng các layouts responsive: `PublicLayout`, `CustomerLayout`, `DashboardLayout`:**
  - `PublicLayout`: Header thanh lịch với logo, menu điều hướng, nút Đăng nhập / Đăng ký, menu hồ sơ khi đã đăng nhập, và Footer liên hệ.
  - `CustomerLayout`: Kế thừa vỏ bọc công khai, tối ưu hóa các liên kết đơn đặt sân và hồ sơ cho khách hàng.
  - `DashboardLayout`: Giao diện quản trị hiện đại cho Quản trị viên (Admin) và Chủ sân (Owner) với thanh bên (Sidebar) phân quyền, drawer responsive trên thiết bị di động, thông tin phiên làm việc và điều hướng chuyên biệt.
- [x] **Đầu việc 5 — Xây dựng các route guards phân quyền: `ProtectedRoute`, `RoleRoute`, `PublicOnlyRoute`:**
  - `ProtectedRoute`: Chặn truy cập trái phép, lưu lại đường dẫn gốc vào `state.from` để chuyển hướng mượt mà sau khi đăng nhập thành công.

  - `PublicOnlyRoute`: Ngăn người dùng đã đăng nhập vào lại các trang Login/Register, tự động chuyển hướng về trang chủ hoặc dashboard phù hợp với vai trò.
