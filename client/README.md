# Frontend React — vị trí giữ chỗ

Frontend bắt đầu ở **P15**, sau khi P14 được nghiệm thu và gate BE_READY là ACCEPTED trong [trạng thái phase](../docs/planning/phase-status.json).

Hiện chỉ tạo thư mục và file hướng dẫn này. React/Vite, dependencies, pages, layouts, components và hooks sẽ được khởi tạo theo [kiến trúc frontend](../docs/architecture.md) khi đến phase tương ứng.

Trong giai đoạn backend, fixture HTML kiểm thử cookie hoặc VNPay return tối thiểu thuộc công cụ kiểm thử backend, đặt trong `server/tests/fixtures/`; không phát triển UI sản phẩm tại đây trước BE-READY.
